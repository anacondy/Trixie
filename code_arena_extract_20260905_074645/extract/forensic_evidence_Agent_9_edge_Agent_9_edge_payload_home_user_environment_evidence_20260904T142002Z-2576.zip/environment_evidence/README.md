## Run it again

The default is the full probe. It performs approximately 45 MB of downloads, a 10 MB upload, a reversible apt installation, isolated pip/npm installs, a 100 MiB disk test, and a controlled 512 MiB allocation.

```bash
chmod +x probe_environment.sh
./probe_environment.sh --full
```

A less invasive run is available:

```bash
./probe_environment.sh --quick
```

Every execution creates a new timestamped directory under `runs/` containing its own raw transcripts, frozen script copy, sandbox/template IDs, timestamps, and hashes.

## Verify this run

cd runs/20260904T142002Z-2576

## Diff two runs

Raw timestamps, process IDs, IP addresses, and timing values are intentionally retained, so a literal diff will include expected volatile fields.

```bash
diff -ru runs/RUN_A/raw runs/RUN_B/raw
```

For programmatic verification metadata, compare the two `manifest.json` files.
